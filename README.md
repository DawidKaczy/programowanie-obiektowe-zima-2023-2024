# Programowanie obiektowe

**Semestr zimowy 2023/2024**

Repozytorium z ćwiczeniami, laboratoriami, kolokwiami i zestawami egzaminacyjnymi z Javy (IntelliJ IDEA) z przedmiotu Programowanie obiektowe.

Każdy podfolder to osobny projekt IntelliJ — otwórz go przez `File → Open` i uruchom klasę `Test*` / `Main`.

## Struktura

| Folder | Opis |
|--------|------|
| `cwiczenia/` | Ćwiczenia z zajęć (od podstaw do generyków) |
| `laboratoria/` | Zadania laboratoryjne |
| `kolokwia/` | Zestawy kolokwialne (K) |
| `egzaminy/` | Zestawy egzaminacyjne (E / M) |
| `przyklady/` | Przykładowe rozwiązania egzaminacyjne |
