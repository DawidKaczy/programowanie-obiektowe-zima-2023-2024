# Java – zadania egzaminacyjne

Projekt z 5 zadań (prawdopodobnie z egzaminu / zajęć).

## Struktura

| Pakiet | Temat |
|--------|--------|
| `zad1_person_record` | Rekord `Person` – walidacja wieku, metoda `isAdult()` |
| `zad2_comparable_car` | Klasa `Car` z `Comparable` (sortowanie po przebiegu, potem roku) |
| `zad3_transporter` | Interfejs `Transporter`, implementacje `Car` / `Helicopter`, `TransportCompany` |
| `zad4_custom_exception` | Własny wyjątek `ValueTooLowException` (+ szkic testu) |
| `zad5_generics_guitar` | Generyki – `compareObjects` dla hierarchii `Guitar` / `ElectricGuitar` |

## Uruchomienie

Projekt IntelliJ IDEA. Każde zadanie ma klasę `Test*` z metodą `main`.
